# 🤖 UKSIVT Schedule Telegram Bot (v1.0)

Асинхронный Telegram-бот на Python (aiogram 3.x) для студентов УКСИВТ. 
Бот автоматически парсит расписание с официального сайта, определяет чётность недели через `<div class="weeknow">`, фильтрует неактивные пары и накладывает актуальные замены.

## 🚀 Функционал
- 📅 Расписание на сегодня и на неделю
- 🔄 Автоматическая обработка и форматирование замен
- 🗓 Фильтрация пар с учетом чётной / нечётной недели
- 👨🏻‍💻 Прямая кнопка связи с разработчиком

## 🛠 Технологии
- **Python 3.11+**
- **aiogram 3.x**
- **BeautifulSoup4 & aiohttp**
- **python-dotenv**
